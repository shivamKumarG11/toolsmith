Why it's safe

The agent's own code never gets the keys.

Fresh code the agent just wrote is untrusted. It runs in a throwaway micro-VM whose egress is enforced in-kernel on the host — unchangeable from inside. The Stripe key is injected only for the verified step, and the spending cap is enforced outside the sandbox.
